# Skill release checklist

- [ ] `SKILL.md` passes the skill validator and contains no scaffold placeholders.
- [ ] Automatic discovery text is precise and does not capture unrelated reporting tasks.
- [ ] Ordinary use requires no Node.js, npm, database, server, or manual CLI pipeline.
- [ ] A realistic invocation produces a directly openable `report.html` bundle.
- [ ] Unknowns, failures, negative findings, conflicts, disclosure restrictions, and source boundaries remain visible.
- [ ] Conditional detail is routed to references rather than duplicated in `SKILL.md`.
- [ ] The optional reference runtime passes its complete Windows, macOS, and Linux CI matrix.
- [ ] English and Chinese user documentation agree.
- [ ] No revoked v0.1.x Release, tag, or archive is restored.
- [ ] Release notes state that implementation checks do not establish scientific truth or institutional approval.
