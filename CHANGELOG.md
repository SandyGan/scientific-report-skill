# Changelog

All notable changes to Scientific Report Skill are documented here.

## [0.2.0] - 2026-08-28

### Changed

- Repositioned the project as a Skill-first scientific report builder.
- Made a directly openable offline `report.html` bundle the primary deliverable.
- Moved Node.js and npm into `tools/reference-runtime/` as an optional private validation implementation.
- Renamed the public repository from `scientific-report-console` to `scientific-report-skill`.

### Removed

- Revoked every public v0.1.x GitHub Release and version tag.
- Removed npm-package installation and manual CLI orchestration from the user workflow.
- Removed local v0.1.x release archives.
